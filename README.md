# Dental Clinic Website

A modern and responsive dental clinic website designed to provide patients with a smooth and engaging browsing experience.

## Overview

This project is a front-end dental clinic website that presents the clinic's services, information, doctors, appointments, blog content, and contact details through a clean and user-friendly interface.

## Features

-  Responsive Home Page
-  Dental Services Section
-  Doctors & Clinic Information
-  Appointment Page
-  Blog & Blog Details
-  Contact Us Page
-  Responsive Design
-  Modern and User-Friendly UI
-  Interactive Front-End Elements

## Technologies

- HTML5
- CSS3
- JavaScript
- SCSS
- Bootstrap
- Font Awesome
- SwiperJS

## Project Structure

## Purpose
The project was created to practice and demonstrate front-end development skills while building a realistic website for a dental clinic.
